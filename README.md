## 📖 Visão Geral

Projetos práticos de Machine Learning supervisionado e não-supervisionado: árvores de decisão, Random Forest, K-Nearest Neighbors, Support Vector Machines, validação cruzada robusta e otimização de hiperparâmetros.

Este repositório reúne projetos práticos desenvolvidos com foco em engenharia de dados e inteligência artificial, demonstrando desde fundamentos teóricos até implementações práticas com validação experimental e métricas salvas.

## 🌟 Destaques do Portfólio

### 🔹 [Diagnóstico de Câncer de Mama com Árvores de Decisão e Validação N-Fold](./01_decision_tree_breast_cancer_crossval.ipynb)
Pipeline completo de classificação no dataset Breast Cancer com protocolo rigoroso de validação cruzada N-Fold, análise de profundidade da árvore e métricas de sensibilidade/especificidade.

- **Stack:** `Scikit-Learn` `Matplotlib` `Seaborn` `Cross-Validation`
- **Notebook:** [`01_decision_tree_breast_cancer_crossval.ipynb`](./01_decision_tree_breast_cancer_crossval.ipynb)

### 🔹 [Modelagem e Avaliação de Risco de Crédito (End-to-End)](./02_analise_risco_credito_end_to_end.ipynb)
Projeto completo de ciência de dados e concessão de crédito: análise exploratória (EDA), tratamento de outliers, engenharia de atributos e comparação de modelos preditivos.

- **Stack:** `Scikit-Learn` `Pandas` `Scipy` `Visualização de Dados`
- **Notebook:** [`02_analise_risco_credito_end_to_end.ipynb`](./02_analise_risco_credito_end_to_end.ipynb)

### 🔹 [Reconhecimento de Dígitos Manuscritos com KNN e Validação Cruzada](./03_knn_classificacao_digitos_crossval.ipynb)
Classificação de dígitos manuscritos no dataset Digits com otimização do número de vizinhos (K), métricas de acurácia e matriz de confusão.

- **Stack:** `KNN` `Classificação Multiclasse` `Scikit-Learn`
- **Notebook:** [`03_knn_classificacao_digitos_crossval.ipynb`](./03_knn_classificacao_digitos_crossval.ipynb)

### 🔹 [Otimização de Hiperparâmetros no Dataset MNIST](./04_otimizacao_hiperparametros_mnist.ipynb)
Técnicas de GridSearch e busca aleatória para maximização do poder de generalização de classificadores em imagens de dígitos.

- **Stack:** `GridSearchCV` `Otimização` `MNIST`
- **Notebook:** [`04_otimizacao_hiperparametros_mnist.ipynb`](./04_otimizacao_hiperparametros_mnist.ipynb)

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/VictorSilvaCamargo/machine-learning-portfolio.git
   cd machine-learning-portfolio
   ```
2. **Crie e ative um ambiente virtual:**
   ```bash
   python -m venv venv
   # Windows:
   .\venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```
3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Inicie o Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
